# Gmail Setup

1. login in gmail and go to https://myaccount.google.com/apppasswords
2. create a new app, called `psmail` (or whatever you want), click `Create`
3. store app password in your password safe
4. imap.gmail.com:993 SSL, smtp.gmail.com 465 (SSL) or 587 (TLS)

There are also more [detailed descriptions](https://www.codewords.ai/blog/imap-password-for-gmail)
